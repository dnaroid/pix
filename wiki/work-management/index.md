# Work management and resources

Session-local todos, saved project tasks and durable resource registry are distinct stores with different authorization and lifecycle rules.

[Wiki home](../index.md)

## Topics

- [Resource registry](registry/index.md) — Project state, publication tags, agent companions and Desktop plan/diff surfaces.
- [Saved project tasks](tasks/index.md) — Project task storage, agent authorization and Desktop task management. Session todos are not saved project tasks.
- [Session todos](todos/index.md) — Planning, initial status, thinking overrides, replay and documentation finalization.
